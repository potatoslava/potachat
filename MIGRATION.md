# Инструкция по переносу проекта CocoDack

## Шаг 1: Экспорт данных со старого проекта

1. Открой терминал в папке проекта
2. Экспортируй данные:
```bash
cd server
node export-data.js
```
3. Сохрани созданный файл `backup-ДАТА.json` - он понадобится позже

## Шаг 2: Перенос кода на новый GitHub

1. Создай новый репозиторий на новом GitHub аккаунте
2. Измени remote в текущем проекте:
```bash
git remote set-url origin https://github.com/НОВЫЙ_АККАУНТ/НОВЫЙ_РЕПО.git
```
3. Запуш код:
```bash
git push -u origin main
```

Если нужен новый git (без истории):
```bash
rm -rf .git
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/НОВЫЙ_АККАУНТ/НОВЫЙ_РЕПО.git
git push -u origin main
```

## Шаг 3: Настройка нового Railway проекта

1. Зайди на railway.app с новым аккаунтом
2. Создай новый проект → Deploy from GitHub repo
3. Выбери свой новый репозиторий
4. Railway создаст два сервиса: web и postgres

### Настройка переменных окружения

В настройках web сервиса добавь переменные:

```env
NODE_ENV=production
JWT_SECRET=твой_секретный_ключ_минимум_32_символа
PORT=3000

# Email (опционально)
EMAIL_USER=твой_email@gmail.com
EMAIL_PASS=пароль_приложения

# Admin (опционально)
ADMIN_SECRET=твой_секретный_код
```

DATABASE_URL автоматически подтянется из postgres сервиса.

## Шаг 4: Импорт данных в новый проект

1. Дождись успешного деплоя на Railway
2. Открой Railway CLI или используй веб-терминал
3. Скопируй файл бэкапа на новый сервер
4. Запусти импорт:

```bash
# Через Railway CLI
railway run node server/import-data.js backup-ДАТА.json

# Или загрузи файл через веб-интерфейс и запусти
node server/import-data.js backup-ДАТА.json
```

## Шаг 5: Проверка

1. Открой новый домен Railway
2. Войди в аккаунт
3. Проверь что все данные на месте:
   - Чаты
   - Сообщения
   - Контакты
   - Настройки

## Важные замечания

⚠️ **Файлы в /uploads не переносятся автоматически**
- Аватарки хранятся в base64 в БД - они перенесутся
- Загруженные файлы (фото/видео) хранятся на диске - нужно копировать вручную

⚠️ **Домен изменится**
- Railway даст новый домен типа `твой-проект.up.railway.app`
- Можно настроить свой домен в настройках Railway

⚠️ **База данных**
- Railway создаст новую пустую PostgreSQL базу
- Импорт данных обязателен для переноса пользователей и сообщений

## Альтернативный способ (если есть доступ к старой БД)

Если у тебя есть прямой доступ к старой базе данных:

```bash
# Экспорт со старого Railway
railway run pg_dump $DATABASE_URL > backup.sql

# Импорт в новый Railway
railway run psql $DATABASE_URL < backup.sql
```

## Помощь

Если что-то пошло не так:
1. Проверь логи в Railway Dashboard
2. Убедись что все переменные окружения настроены
3. Проверь что миграции Prisma применились: `railway run npx prisma migrate deploy`
